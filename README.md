# Automated Login Test

This project demonstrates automated testing of login functionality using Selenium.

## 📌 Objective
To automate login testing for a web application including both positive and negative test cases.

## 🧪 Test Cases Covered
- ✅ Valid Login (correct username & password)
- ❌ Invalid Login (wrong credentials)
- ⚠️ Empty Fields (no input)

## 🛠 Tools & Technologies
- Python
- Selenium WebDriver

## 🌐 Test Website
https://the-internet.herokuapp.com/login

## ▶️ How to Run
1. Install Python
2. Install Selenium:
   pip install selenium
3. Run the script:
   python login_test.py

## 📄 Description
The script opens a browser, performs login actions, and validates different scenarios like valid login, invalid login, and empty input fields.
